Recommended workflow from repo root:

1. Copy/extract this bundle into the repository root, preserving folders.

2. Validate without model calls:
   python .\run_robustness_r4.py --dry-run

3. Run first 4 tasks only:
   python .\run_robustness_r4.py --limit 4

4. Inspect:
   Get-Content .\results\robustness\r4_rationale_raw.csv -First 6

5. If the four outputs follow LETTER | one short sentence, continue:
   python .\run_robustness_r4.py

The runner resumes automatically from the CSV by task_id.

6. After 840/840:
   python .\analyze_r4.py

Important:
- Do not modify prompts_r4.json after the first model call.
- R4 is exploratory; Primary remains the hypothesis test.
- Rationales are generated explanations, not hidden/internal model reasoning.
